AI Office Workspace
機能 インストール 動作環境 注意事項
Windows 10 / 11（64-bit）向け

AI の回答を、そのまま資料に。

ChatGPT・Claude・DeepSeek・Qwen と Google Docs・Sheets・Slides の公式サイト、 Excel / Word / Slide 風のエディタを 1 つのウィンドウに。AI が作った回答や表を、コピーせずにその場で表計算・文書・ スライドへ変換して編集できます。API キーは不要です。

AI Office Workspace をインストール

バージョン 1.0.3 ／ setup.exe（約 230 MB）／ 管理者権限は不要です

ダウンロード（setup.exe）

ダウンロードした AI-Office-Workspace-Setup.exe を実行して端末に インストールしたうえで、スタートメニューの「AI Office Workspace」から 起動してください。ポータブル版（展開して終わりの形式）は提供していません。

できること

4 つの AI と 3 つのエディタを、切り替えながら 1 画面で使います。

🤖

4 つの AI をタブで比較

ChatGPT / GLM / DeepSeek / Qwen を公式サイトのまま表示。ログイン情報と Cookie はサービスごとに分離され、タブを切り替えてもページは再読み込みされません。

📊

Excel・Word・Slide エディタ

セル編集・数式・複数シート、見出しや書式付きの文書、16:9 のスライド編集と プレゼンテーション表示に対応しています。

✨

AI 回答をその場で変換

最新の回答を取得し、テキスト・表・文書・スライドのいずれかへ変換して挿入。 Markdown の表や見出し構造をそのまま活かせます。

📁

既存ファイルの取り込み

.xlsx / .csv / .docx / .pptx をドラッグ＆ドロップで取り込み。 AI が生成したファイルをダウンロード後、そのまま編集へ回せます。

🔒

変換はすべて端末内で処理

回答の変換・ファイルの読み取りはローカルで行い、外部の AI API は呼びません。 API キーの登録も不要です。

💾

自動保存と復元

編集が止まると自動保存され、次回起動時に内容・モード・ウィンドウ配置が そのまま復元されます。手動保存は Ctrl+S です。

インストール手順

setup.exe は端末にインストールして使う形式です（展開や別途ツールは不要）。

  1. setup.exe をダウンロード

    上のボタンから AI-Office-Workspace-Setup.exe を保存します。

  2. setup.exe を実行

    保存した setup.exe をダブルクリックします。セットアップウィザードが 日本語で表示されます。

  3. 画面の案内に従ってインストール

    インストール先は %LOCALAPPDATA%\Programs\AI Office Workspace です。 管理者権限（UAC）は求められません。デスクトップ／スタートメニューの ショートカットは既定で作成され、ウィザードの画面で外すこともできます。

  4. スタートメニューから起動

    インストール完了時に「AI Office Workspace を起動する」を選ぶか、 スタートメニューの「AI Office Workspace」から起動します。

初回起動時に SmartScreen の警告が出る場合があります。 本アプリはコード署名を行っていないためです。画面の「詳細情報」→「実行」で インストール／起動できます。

動作環境

インストール前に端末の環境をご確認ください。

項目 要件
OS Windows 10 / Windows 11（64-bit）
ディスク インストール先に数百 MB の空き容量（Qt WebEngine を同梱しています）
画面 1100 × 650 以上（初期サイズ 1500 × 900）
ネットワーク AI サイトの利用時に必要（各サービスへのログインは利用者ご自身で行います）
その他 Python / Node.js のインストールは不要です（実行に必要なものはすべて同梱）

インストール後の保存場所

プログラム本体とユーザーデータは分けて保存されます。

種類 場所
プログラム本体 %LOCALAPPDATA%\Programs\AI Office Workspace
ショートカット スタートメニュー（デスクトップはインストール時の任意選択）
設定・自動保存・ログイン情報 %APPDATA%\AI Office Workspace
AI が生成したダウンロード ドキュメント\AI Office Workspace\downloads

アンインストールしても設定・ログイン情報・ダウンロードしたファイルは残ります。 完全に削除する場合は %APPDATA%\AI Office Workspace を削除してください。

注意事項

項目 内容
配布形式 zip（中にインストーラー setup.exe）。インストールして使う形式で、 ポータブル版は配布していません。
コード署名 未署名のため、初回に SmartScreen の警告が表示されることがあります。
AI サイトの利用 各サービスのログイン・利用規約に従ってご利用ください。サイト側の仕様変更や 制限により、回答を取得できない場合があります。
アカウント情報 パスワードや API キーを保存・送信する機能はありません。ログイン状態は サービスごとのプロファイルにのみ保存されます。
取り込みの制限 図形・画像・一部の書式は引き継がれません。20 MB を超えるファイルは取り込めません。
